This is a sample post. To write a new one, add a file to `src/content/blog/`, for example `my-trip-to-chicago.md`, with a few lines at the top:

```
---
title: My trip to Chicago
date: 2026-11-12
summary: One sentence that shows up in the list of posts.
---
```

Then write the post underneath in plain text. A few handy bits of formatting:

- Put `**two stars**` around words to make them **bold**
- Start a line with `## ` for a heading
- Start lines with `- ` for a list, like this one
- Links look like `[link text](https://example.com)`

Add `draft: true` at the top to keep a post hidden until it's ready.
